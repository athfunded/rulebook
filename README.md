# ATH Funded — Rulebook

The published rules for ATH Funded Evaluations and Funded Accounts.

The English text is the binding version. The Russian file is a reference
translation provided for convenience; where the two differ, the English
text governs.

## Versions

| Version | Binding text | Reference translation |
|---------|--------------|-----------------------|
| V0.1    | [`v0.1/rulebook.en.md`](v0.1/rulebook.en.md) | [`v0.1/rulebook.ru.md`](v0.1/rulebook.ru.md) |

Rulebook V0.1 defines the rules for all ATH Funded Evaluations and Funded
Accounts issued under this version. It is not an agreement in respect of an
active account until accounts are offered for purchase and a purchaser is
bound to a specific version of the rules.

## Verifying the text

Every revision is a commit in this repository, so the full history is public
and each version can be read exactly as it stood at any point in time. The
Rulebook page on the site links to the commit its text was taken from.

To check a copy of the text against a published version:

```
shasum -a 256 v0.1/rulebook.en.md
```

For V0.1 this is:

```
f82f4f77f219325aa099aa2d67f2f360925ad6acb2786ff89724c1f8605184ab
```

## What is not here yet

A machine-readable manifest of the document set, and the cryptographic
fingerprint recorded on a blockchain that each purchase is linked to, are
intended but not yet published. The effective-date, notice, and
version-application procedure remain subject to legal review before accounts
are offered for purchase.
